# 04. 설계 검증 실험

설계의 핵심 가정을 실제로 확인한 실험이다(2026-10-27, 개발 PC: Windows 10, Python 3.12, 모델 `gpt-5.5`).
표본이 작으므로 경향을 보는 용도이며, 구현 후 더 큰 표본으로 다시 측정한다.
실험 스크립트는 일회성이라 저장소에 넣지 않았다.

**안전 조치**: LLM 이 생성한 코드는 사람이 먼저 읽어 확인한 뒤 빈 임시 폴더에서
`python -I -X utf8`, 10초 제한, 최소 환경변수(API 키 없음)로 실행했다.

## 본문·예제 (01·02 문서 관련)

| 실험 | 방법 | 결과 | 설계 반영 |
|---|---|---|---|
| **A** null 허용 필드 | strict 구조화 출력의 `target: str \| None` 에 요청 3개 | **3/3 정확**("2장 3절" → `"2.3"`, "1장" → `"1"`, 인사 → `null`), 호출당 2~3초 | `TaskPlan.target` 필드 사용 |
| **B-1** 예제 정확성 | 4개 주제로 절 + 예제 생성 후 실행·출력 비교 | 실행한 6개 모두 본문 출력과 일치(쉬운 주제만) | 기본 품질은 양호, 큰 표본 재측정 필요 |
| **B-2** 구조 준수 | 위와 같음 | pathlib 주제는 **2회 모두 `examples` 가 빈 목록**, 코드는 본문 마크다운에 섞임 | 응답 검증·재요청, 본문 코드 추출 |
| **B-3** 결정성 | 위와 같음 | datetime 예제가 실행일과 같은 날짜라 **우연히 일치**(다른 날엔 틀림). 같은 날 2회 실행 비교로는 못 잡음 | 정적 검사 + 날짜 고정 규칙 |
| **B-4** 응답 시간 | 호출별 시간 측정 | 절 작성 보통 8~14초. 1개 주제가 **180초 타임아웃 2회 연속**, 첫 실행에서는 다른 주제가 **20분 넘게 멈춤** | 타임아웃·재시도 필수, 절 단위 저장, **0단계** |
| **C** 격리 환경 | Docker 확인 | 설치됐으나 엔진 꺼짐 | 하위 프로세스 격리 기본, Docker 선택 |

## 시각화 (03 문서 관련)

| 실험 | 방법 | 결과 | 설계 반영 |
|---|---|---|---|
| **E1** 도구 | 설치 여부 확인 | Node 24·Chrome 있음 / Graphviz·Java·pandoc 없음 / Docker 엔진 꺼짐 | Mermaid 로 통일 |
| **E2-a** LLM 이 Mermaid 직접 작성 | 순서도·시퀀스·클래스·상태 4종 렌더링 | 첫 시도 **3/4**. 순서도는 따옴표 없는 라벨의 `input()` 괄호로 문법 오류 → 오류를 주자 **1회에 수정 → 4/4** | 렌더링 → 수정 반복(최대 2회) |
| **E2-b** JSON → 변환기 | 노드·연결 JSON 3회 → 직접 만든 변환기 | 처음 **0/3** — LLM 이 3회 모두 끝 노드 id 를 `end` 로 지었고 Mermaid **예약어**였음(변환기 버그). id 만 바꾸자 **3/3** | 변환기가 id 직접 부여, 변환기 단위 테스트 |
| **E2** 육안 확인 | PNG 렌더링 후 확인 | 한글 정상, 내용이 지시와 일치. 기본 테마는 보라색 | 책 전용 테마(흑백 인쇄 고려) |
| **E2** 렌더링 시간 | 측정 | 그림 하나 6~11초(대부분 Chrome 시작) | 일괄 렌더링 + 해시 캐시 |
| **E3** matplotlib 한글 | 기본 글꼴 vs 맑은 고딕 | 기본 글꼴(DejaVu Sans) **한글 20자 모두 누락**, 맑은 고딕 0건 | 공개 한글 글꼴 포함, 누락 경고 검사 |
| **E3** 결정성 | 같은 그림 2회 저장 | SVG 는 **매번 다름**, `svg.hashsalt` + `Date=None` 고정 시 동일. PNG 는 같은 PC 에서 동일 | 메타데이터 고정 기본값 |
| **E4** 코드에서 클래스 추출 | 이 프로젝트에 pyreverse | 2.7초, 상속 관계 정확(`Task → TaskPlan`, 작업 노드 3개 → `WorkerNode`). Protocol 구현 관계 누락, 모듈 의존 화살표 25개 | 추출 우선 + 필터·보충 규칙 |
| **E5** 실행 추적 | `sys.settrace` 로 4줄 반복문 | 9단계 표 정확. 예제 출력이 표와 섞임 | 단계 수 상한, 출력 분리 |
| **E6** 그림 필요성 검토 | 후보 6개(정답: 유지 2, 제거 3, 선택 1)를 독립 검토자가 2회 판정 | 꾸밈·무관한 그림 3개는 **2회 모두 정확히 제거**. 핵심 그림은 **실행마다 판정이 달라짐**(추적 표 `keep`↔`change_type`, 흐름도 `merge`↔`drop`), 일치 5/6·4/6. "기본은 제거" 지시가 과도한 제거를 부름 | 기준별 점수, 2회 판정, 불일치는 사람 승인 |
| **E7** 그림 ↔ 코드 일치 | 그림엔 "다시 입력" 반복, 코드는 1회만 묻고 종료(의도적 불일치) | **핵심 불일치 정확히 검출**, 숨은 차이도 지적(`isdigit()` 은 음수·소수 불인정). 시작·끝 노드를 "대응 없음"으로 표시 | 노드-코드 대응표 방식 채택, 시작·끝 노드 예외 |
